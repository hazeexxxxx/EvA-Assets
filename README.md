# EvA Assets

Public runtime assets for EvA-Client. This repository intentionally contains only icon files and the remote manifest.
Passive skill icons and hero-to-skill mappings are sourced from public hero data provided by [Rone Arena API](https://arena.rone.dev/), maintained by ridwaanhall / RoneAI. In-game icons and related game assets are © Moonton. EvA-Assets is an unofficial project and is not affiliated with or endorsed by Moonton.
